# Safety / copyright

The reference video teaches **visual style and editing grammar**.

## Allowed

- Infer palette, typography feel, pacing, motion, transitions, density
- Build an original composition influenced by that grammar
- Source independent photos/icons/BGM/SFX via media-use or licensed/public sources

## Not allowed

- Reproducing copyrighted frames, clips, logos, or proprietary UI verbatim
- Instructing the system to "recreate this Short shot-for-shot"
- Shipping reference video pixels inside the output (except user-owned media they explicitly provide as assets)

If a user asks to clone a specific creator's video content, refuse the copy and continue with **style grammar + original assets** only.

## Style packs

Frozen packs under `styles/` may include reference screenshots for vision grounding. Those stills are **analysis aids**, not assets to composite. Packs that set `watermark.enabled: false` must never emit the source channel URL (e.g. `insiderforce.io`).

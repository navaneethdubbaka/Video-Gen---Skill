# Hook formulas (scroll-stoppers)

Each variant must use a **different** formula. On-screen ≤6–8 words **total** (incl. asset text). Prefer VO 1.5–5s. Pattern **A** (sticker) or **B** (big number) — never a body-scene hybrid.

For **edtech / LLM explainers** (default niche): read [edtech-hooks.md](edtech-hooks.md) first — clarity + knowledge contract beats mystery.  
Visual anti-patterns: [visual-quality.md](visual-quality.md).

## Formulas

### `myth_bust` ★ edtech default
Correct a belief the audience already holds.  
Examples: `bigger wasn't better` · `you learned this wrong`  
Pattern: **A** or **B** — strike the myth by 3s, show the short true claim. Mute must still read.

### `knowledge_gap` ★ edtech
Specific fact undercut.  
Examples: `175B lost to 1.3B` · `humans preferred the small one`  
Pattern: **B** with vs chip proof by 3s.

### `countdown_promise` ★ edtech
Clear teaching contract.  
Examples: `in 20s: why 1.3B won` · `3 things that matter`  
Pattern: **A** or type — most reliable for longer VOs.

### `shock_claim`
Bold counter-intuitive statement.  
Examples: `it was never encryption` · `they shipped it broken`  
Pattern: prefer **A** with subject sticker. One claim line — no supporting bullet card.

### `giant_number`
Huge number + **outcome unit** (not a bare digit).  
Examples: `1.3B beat 175B` · `117M parameters` · `10× overnight`  
Pattern: **B** — type-led + proof chip by 3s. Do **not** add a dual-column report card. Bare `1.3B` alone fails mute edtech test.

### `forbidden`
Deny list energy in one line.  
Examples: `no GPU` · `no fine-tune`  
Pattern: **A** with ✕ badge, or **B** if a zero/none number.

### `quiz_dare` ★ edtech
Force a pick.  
Examples: `which model won — A or B?`  
Pattern: **A** — reveal after a beat; comments extend reach.

### `open_loop` ⚠ demote for edtech
Promise unfinished story.  
Examples: `then we decoded it` · `part you missed`  
Pattern: **A**. For education VOs ending in “why?”, **rewrite on-screen** to name the topic (`why humans preferred 1.3B`) — never bare `why?`. Do not dump body explainer cards.

### `villain`
Name the antagonist / lazy assumption.  
Examples: `everyone trusted the token` · `base models ignore you`  
Pattern: **A**

### `before_after`
Two-beat flip inside the hook (still short).  
On-screen: `fine-tune required` → punch to `zero-shot works`  
Pattern: **B** then micro cut, or single line with strikethrough — not a full before/after report.

## Writing rules

1. **Specific > clever.** Nouns from the actual video topic.
2. **Spoken energy.** Words you’d say out loud in 1 breath.
3. **No textbook titles.** Ban: “Introduction”, “Overview”, “What is GPT”, “Parameter Efficiency”, “Model Size vs …”. Titles inside images count.
4. **Romanize Telugu** for glyphs; keep meaning.
5. **Mute knowledge-contract test:** at 0s, can you tell what you’ll learn? If not, rewrite `on_screen`.
6. **One claim, one accent.** No WINNER badge + WINNER footer + “BEAT” headline saying the same thing thrice.
7. **Motion:** plan proof-by-3s + mid-VO beat when writing the recipe.
8. **Mapping seed → formula (edtech):** misconception → `myth_bust`; big stat contrast → `knowledge_gap` / `giant_number`+proof; “in Ns…” → `countdown_promise`; A/B → `quiz_dare`.

## Mapping user seeds

| User seed vibe | Formula |
| --- | --- |
| Big stat | `giant_number` |
| “Nobody tells you…” | `shock_claim` or `villain` |
| “No X / without Y” | `forbidden` |
| “Wait until…” / cliffhanger | `open_loop` |
| Contrast then/now | `before_after` |

If two seeds map to the same formula, rewrite the weaker one to the nearest unused formula **without** changing the claim.
